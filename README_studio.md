# Forest Camera Studio

Windows用のPythonデスクトップアプリです。Blender 5.2.1との連携を確認しています。

## 起動

`open_studio.cmd` をダブルクリックしてください。初回は `uv` がPySide6をインストールします。

PowerShellから起動する場合:

```powershell
uv run python -m studio.app
```

別のシーンを指定して起動する場合:

```powershell
uv run python -m studio.app "C:\path\scene.blend"
```

1. 標準では `flow_forest.blend` が選択されています。別のシーンは「シーンを開く」で選択します。
2. 「Blenderを起動」を押します。
3. シェーダーの準備後、アプリ内にカメラのプレビューが表示されます。

Blenderも別ウィンドウで起動します。描画にはBlenderのGUIと3Dビューが必要なので、そのウィンドウを閉じないでください。通常の画面操作はPythonアプリから行えます。別シーンへの変更は、保存してアプリを再起動してから行います。

Blenderの標準パスは `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` です。見つからない場合は選択画面が出ます。環境変数 `BLENDER_EXE` で指定もできます。

## カメラ操作

まずプレビューをクリックしてフォーカスを合わせます。

| 操作 | 動作 |
|---|---|
| 右ボタンを押しながらドラッグ | 視線の変更 |
| W / S | 前進 / 後退 |
| A / D | 左 / 右 |
| Q / E | 下降 / 上昇 |
| 矢印キー | 視線の変更 |
| Shift + 移動キー | 高速移動 |
| マウスホイール | 移動速度の変更 |
| 1〜9 | 一覧の対応するカメラへ切り替え |
| F12 | 現在のプレビューをPNG撮影 |

キーボード操作はプレビューにフォーカスがあるときだけ有効です。フォーカスを外すと押下状態を解除します。マウスの視線操作は画面端を越える無限回転ではなく、右ドラッグを繰り返す方式です。

カメラ一覧で切り替え、「現在位置を複製」で独立したカメラを追加できます。レンズ、被写界深度、F値、ピント距離、ピント対象を右側で設定します。ピント対象を選ぶと距離の手動指定は無効になります。

### オブジェクトへのオートフォーカス

「ピント対象」でオブジェクトを選ぶと、被写界深度と「対象にピントを追従」が有効になります。カメラの移動や対象のアニメーションに合わせて、Blenderがピントを更新します。「ピント距離」には現在の焦点面までの距離を表示します。

「オブジェクト」タブで選択した対象は、「選択オブジェクトをピント対象にする」でも設定できます。猫の顔に合わせる場合は `Cat head` を選択してください。ピントはオブジェクトの原点に合います。

AFをOFFにすると、その時点のピント距離を保持し、距離を手動で編集できます。対象の選択は残るので、再びONにすれば同じ対象へ追従します。被写界深度だけをOFFにした場合も、対象設定は保持します。

設定はカメラごとに管理し、`.blend` に保存します。EEVEEプレビューで確認でき、高品質PNGでは撮影時のピント距離を固定したコピーを使います。高速表示モードでは被写界深度が表示されないため、確認にはEEVEEを選んでください。

## プレビューと撮影

- **EEVEE**: シーンの光と被写界深度を反映した軽量プレビュー。Cyclesの最終画像とは見え方が異なります。
- **高速**: 材質色の表示。光と被写界深度の確認はEEVEEへ切り替えてください。
- 解像度と目標FPSを選択できます。実際のFPSはシーンとGPUの負荷に依存し、画面上部に表示されます。
- 「移動中は解像度を下げる」が有効なとき、移動中は約67%の解像度で描画し、停止後に戻します。停止直後のPNG撮影もその時点で表示している解像度になります。
- 「PNG撮影」は表示中の画像を `studio_output/screenshots/` へ保存します。
- 「高品質PNG」は現在のシーン・カメラ・フレームを作業用スナップショットに保存し、別プロセスでCyclesを実行します。シーンの出力解像度を100%で使い、48サンプル・デノイズ有効です。CUDAが利用可能ならGPUを使います。
- 高品質出力は `studio_output/renders/` にPNG、スナップショットの `.blend`、ログを保存します。出力中もプレビュー操作はできます。アプリ終了時に実行中のレンダーは停止します。

## 共通タイムラインとアニメーション

開始・終了フレーム、FPSを設定し、再生・停止・フレーム移動ができます。既存のBlenderアニメーションも再生できます。負荷が高い場合は表示フレームを飛ばすため、プレビューは書き出し動画の品質・フレーム保証とは異なります。

- 「カメラのキーを追加」: 現在フレームのカメラ位置、回転、焦点距離、ピント距離、F値を記録します。
- 「カメラ移動を記録」: タイムラインを進めながらカメラのキーを追加します。もう一度押すと停止します。終了フレームでも自動停止します。
- 通常のアニメーション再生中は手動カメラ移動を無効にします。移動記録中は操作できます。
- 「オブジェクト」タブ: 対象の位置・回転・スケールを編集し、現在フレームにキーフレームを追加できます。オブジェクト選択時に現在値を読み込みます。再生中の数値表示の追従は初期版では行いません。
- 録画MP4の直接出力、歩行などのリグ動作編集、クリップ編集、キーの削除・補間編集、カメラ間のカット編集は今後の追加範囲です。

森の猫は複数の部品で作られています。猫全体の動きを作るには、Blenderで親オブジェクトへまとめるか、リグを付けてから使ってください。

## 保存

「プロジェクトを保存」で `.blend` にカメラとアニメーションを保存します。標準保存先は `studio_output/<scene>_studio.blend` です。アプリの表示品質・移動速度は同名の `.studio.json` に保存し、次回その `.blend` を開いたときに復元します。

元のシーンは自動では上書きしません。同じファイルへの保存を選択した場合は確認が出ます。アプリ終了前に必要な変更を保存してください。

アニメーションが付いたカメラやオブジェクトを手動で変更した場合、その変更を再読込後も保つには現在フレームにキーフレームを追加してください。高品質PNGの撮影ではカメラの現在姿勢を固定したコピーを使い、元のカメラのキーフレームは変更しません。

## 構成

- `studio/app.py`: PySide6の画面、入力、プロセス管理。
- `studio/bridge.py`: Blenderのメインスレッドで操作・描画・アニメーションを実行。
- `studio/transport.py`: 認証付きlocalhost JSON通信と共有メモリのRGBA映像。
- `studio/render_frame.py`: 高品質な静止画出力。
- `studio/smoke.py`: 実アプリとBlenderを起動する統合検証。

オブジェクトに安定したIDを付け、カメラ・オブジェクトのキーフレームをBlenderのデータへ保存しています。今後、経路・アニメーションクリップ・リグ制御の画面とコマンドを追加できる構成です。

接続・描画エラーのログは `studio_output/blender_bridge.log` です。

統合検証を実行する場合（テスト用ウィンドウとBlenderが開きます）:

```powershell
uv run python -m studio.smoke
```

結果は `studio_output/smoke_results.json`、画面は `studio_output/smoke_app.png` に出力します。

オートフォーカスの統合検証は `uv run python -m studio.autofocus_smoke` で実行できます。カメラ移動・対象アニメーションへの追従、カメラごとの設定、AF解除時の距離保持を検証し、`studio_output/autofocus_results.json` に結果を保存します。

## このPCでの検証結果

RTX 5060 Ti / Blender 5.2.1 / 森のシーンでの測定値です。シェーダー準備後の連続表示を測定しました。

| 設定 | 実測 |
|---|---|
| EEVEE 720×480 / 目標15fps | 約12.8fps |
| EEVEE 480×320 / 目標15fps | 約12.9fps |
| 高速 480×320 / 目標30fps | 約22fps |

実アプリでのWキー、右ドラッグ、焦点距離入力、PNG撮影、高品質PNG出力を確認しました。保存ファイルを別のBlenderプロセスで再読込し、カメラ移動・オブジェクト移動のキーフレームと、高品質出力用のカメラ姿勢・焦点距離も確認しました。
